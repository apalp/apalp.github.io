## 核心概念

杨辉三角（Pascal's Triangle）是二项式系数在三角形中的一种几何排列，是中国古代数学的重要成就之一。

### 形式
```
        1
       1 1
      1 2 1
     1 3 3 1
    1 4 6 4 1
   1 5 10 10 5 1
  1 6 15 20 15 6 1
```

### 基本规律
1. 每行首尾都是1
2. 每个数等于它上方两数之和
3. 第n行有n个数字

## 详细内容

### 一、与组合数的关系

杨辉三角的第n行第k个元素（从0开始计数）等于 C(n, k)：

```
Row n: C(n,0) C(n,1) C(n,2) ... C(n,n)
```

**验证**：
```
Row 4: 1  4  6  4  1
C(4,0)=1, C(4,1)=4, C(4,2)=6, C(4,3)=4, C(4,4)=1
```

### 二、递推公式

杨辉三角满足：
```
C(n, k) = C(n-1, k-1) + C(n-1, k)
```
边界条件：
```
C(n, 0) = C(n, n) = 1
```

### 三、重要性质

| 性质 | 描述 |
|------|------|
| 对称性 | 第n行左右对称 |
| 行和 | 第n行所有元素之和为 2ⁿ |
| 斜率和 | 某斜线上元素之和构成 Fibonacci 数列 |

### 四、与二项式定理

```
(a + b)ⁿ = Σ C(n,k) × aⁿ⁻ᵏ × bᵏ (k=0 to n)
```

例如 (a+b)³ = C(3,0)a³ + C(3,1)a²b + C(3,2)ab² + C(3,3)b³

## 例题与应用

### 例题1：打印杨辉三角前n行
```python
def print_pascal(n):
    triangle = []
    for i in range(n):
        row = [1] * (i + 1)
        for j in range(1, i):
            row[j] = triangle[i-1][j-1] + triangle[i-1][j]
        triangle.append(row)
        print(row)
```
**输出**：
```
[1]
[1, 1]
[1, 2, 1]
[1, 3, 3, 1]
[1, 4, 6, 4, 1]
```

### 例题2：空间优化（单行）
```python
def pascal_row_k(k):
    """求杨辉三角第k行（从1开始计数）"""
    result = [1]
    for i in range(1, k):
        result.append(result[-1] * (k - i) // i)
    return result
```
例如 k=5 返回 [1, 4, 6, 4, 1]

### 例题3：LeetCode 典型题
```python
# 119. 杨辉三角 II
# 返回杨辉三角第 rowIndex 行
def getRow(rowIndex):
    row = [1]
    for i in range(1, rowIndex + 1):
        row.append(row[-1] * (rowIndex - i + 1) // i)
    return row
```

### 例题4：求特定位置的值
```python
def pascal_value(n, k):
    """返回第n行第k个元素（从0开始）"""
    result = 1
    for i in range(k):
        result = result * (n - i) // (i + 1)
    return result
```

### 应用场景

1. **概率论**：计算二项分布的概率
2. **组合数学**：计算组合数
3. **算法优化**：某些动态规划问题可用杨辉三角优化
4. **高考数学**：二项式定理
5. **图像处理**：某些滤波器系数

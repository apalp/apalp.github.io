## 核心概念

差分进化算法（DE）和遗传算法（GA）都是进化计算的重要分支，属于元启发式算法（Metaheuristic），用于求解复杂的优化问题。

### 基本思想
模拟自然界的进化过程，通过选择、交叉（杂交）、变异等操作逐步优化解的质量。

### 适用场景
- 非凸、非线性、多峰优化问题
- 传统优化方法难以求解的问题
- 黑盒优化问题（目标函数不可微或没有解析表达式）

## 详细内容

### 一、遗传算法（Genetic Algorithm, GA）

#### 1. 基本概念
- **个体（Individual）**：解的编码表示
- **种群（Population）**：一组候选解
- **适应度（Fitness）**：衡量解的优劣
- **基因（Gene）**：编码中的基本单元

#### 2. 算法流程
```
1. 初始化种群
2. 计算适应度
3. 选择（Selection）
4. 交叉（Crossover）
5. 变异（Mutation）
6. 重复 2-5 直到满足终止条件
```

#### 3. 核心操作

**选择**：根据适应度选择父代
- 轮盘赌选择
- 锦标赛选择
- 排名选择

**交叉**：组合两个父代产生子代
- 单点交叉
- 多点交叉
- 均匀交叉

**变异**：随机改变个体的某些基因
```
变异前: 1 0 1 1 0 0 1
变异后: 1 0 0 1 0 0 1
```

### 二、差分进化算法（Differential Evolution, DE）

#### 1. 基本概念
差分进化是一种专门用于实数编码的进化算法，由 Storn 和 Price 于 1997 年提出。

#### 2. 算法流程
```
1. 初始化种群
2. 对每个个体：
   a. 变异：生成变异向量
   b. 交叉：生成试验向量
   c. 选择：根据适应度选择
3. 重复直到满足终止条件
```

#### 3. 核心操作

**变异策略 DE/rand/1**：
```
v = x_r1 + F * (x_r2 - x_r3)
```
其中 F 是缩放因子（通常 0.5-1.0）

**交叉**：
```
u_j = v_j, 如果 rand <= CR 或 j == j_rand
     x_j, 否则
```
CR 是交叉概率（通常 0.1-1.0）

**选择**：
```
x_new = u, 如果 f(u) <= f(x)
        x,  否则
```

#### 4. 常见变异策略
| 策略 | 公式 |
|------|------|
| DE/rand/1 | v = x_r1 + F(x_r2 - x_r3) |
| DE/best/1 | v = x_best + F(x_r1 - x_r2) |
| DE/rand-to-best/1 | v = x_r1 + F(x_best - x_r1) + F(x_r2 - x_r3) |
| DE/best/2 | v = x_best + F(x_r1 - x_r2 + x_r3 - x_r4) |

### 三、算法对比

| 特性 | 遗传算法 (GA) | 差分进化 (DE) |
|------|-------------|---------------|
| 编码方式 | 二进制/实数 | 实数 |
| 变异方式 | 随机翻转变异 | 差分变异 |
| 搜索能力 | 较强 | 强 |
| 收敛速度 | 中等 | 快 |
| 参数数量 | 较少 | 较多 |
| 应用场景 | 组合优化、函数优化 | 连续优化 |

## 例题与应用

### 例题1：GA求解函数最大值
**问题**：求 f(x) = x * sin(10πx) + 1 在 [-1, 2] 上的最大值

```python
import random
import math

def fitness(x):
    return x * math.sin(10 * math.pi * x) + 1

def genetic_algorithm(pop_size=50, n_generations=100, 
                      mutation_rate=0.01, bounds=(-1, 2)):
    # 初始化
    population = [random.uniform(*bounds) for _ in range(pop_size)]
    
    for gen in range(n_generations):
        # 计算适应度
        fitness_values = [fitness(x) for x in population]
        
        # 轮盘赌选择
        total_fitness = sum(fitness_values)
        probabilities = [f/total_fitness for f in fitness_values]
        
        new_population = []
        for _ in range(pop_size):
            # 选择两个父代
            parents = random.choices(population, weights=probabilities, k=2)
            child = (parents[0] + parents[1]) / 2  # 简单交叉
            
            # 变异
            if random.random() < mutation_rate:
                child += random.gauss(0, 0.1)
                child = max(bounds[0], min(bounds[1], child))
            
            new_population.append(child)
        
        population = new_population
    
    best_x = max(population, key=fitness)
    return best_x, fitness(best_x)
```

### 例题2：DE求解Rastrigin函数
```python
import numpy as np

def rastrigin(x):
    A = 10
    n = len(x)
    return A * n + sum(x**2 - A * np.cos(2 * np.pi * x))

def differential_evolution(func, bounds, n_pop=50, n_iter=500, F=0.5, CR=0.7):
    n_dim = len(bounds)
    
    # 初始化种群
    pop = np.random.uniform(bounds[:, 0], bounds[:, 1], (n_pop, n_dim))
    fitness = np.array([func(ind) for ind in pop])
    
    best_idx = np.argmin(fitness)
    best = pop[best_idx].copy()
    
    for _ in range(n_iter):
        for i in range(n_pop):
            # 变异：随机选择3个不同于i的个体
            indices = [j for j in range(n_pop) if j != i]
            r1, r2, r3 = np.random.choice(indices, 3, replace=False)
            
            # DE/rand/1 策略
            mutant = pop[r1] + F * (pop[r2] - pop[r3])
            
            # 交叉
            trial = mutant.copy()
            j_rand = np.random.randint(n_dim)
            for j in range(n_dim):
                if np.random.random() < CR or j == j_rand:
                    trial[j] = mutant[j]
                else:
                    trial[j] = pop[i][j]
            
            # 选择
            trial_fitness = func(trial)
            if trial_fitness <= fitness[i]:
                pop[i] = trial
                fitness[i] = trial_fitness
                
                if trial_fitness < fitness[best_idx]:
                    best_idx = i
                    best = trial.copy()
    
    return best, func(best)
```

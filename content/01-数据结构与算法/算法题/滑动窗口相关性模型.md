## 核心概念

滑动窗口（Sliding Window）是一种基于双指针的算法技巧，通过在数组或链表上维护一个可变大小的窗口来解决特定类型的问题。

### 基本思想
1. 使用两个指针维护一个窗口
2. 右指针扩展窗口，左指针收缩窗口
3. 根据问题条件调整窗口大小
4. 在窗口滑动的过程中寻找最优解

### 适用场景
- 子串/子数组问题
- 最值问题
- 去重问题
- 连续性约束问题

## 详细内容

### 一、算法思想

#### 1. 维护窗口的不变式
```
[left, right] 表示当前窗口
[left, right) 或 [left, right] 根据具体问题确定
```

#### 2. 滑动过程
```
初始：left = 0, right = 0, 窗口为空
扩展：right++, 增加元素
收缩：left++, 移除元素
重复直到 right 到达末尾
```

#### 3. 复杂度分析
- **时间复杂度**：O(n)，每个元素最多被处理两次
- **空间复杂度**：O(k)，k为窗口大小或哈希表大小

### 二、实现方式

#### 1. 固定窗口大小
```python
def fixed_window(arr, k):
    n = len(arr)
    window_sum = sum(arr[:k])
    max_sum = window_sum
    
    for i in range(k, n):
        window_sum += arr[i] - arr[i-k]
        max_sum = max(max_sum, window_sum)
    
    return max_sum
```

### 三、典型数据结构

| 数据结构 | 适用场景 |
|----------|----------|
| 数组 | 固定窗口，简单累加 |
| 哈希表 | 需要判断元素是否存在/计数 |
| 队列 | 需要维护元素顺序 |
| 单调队列 | 求滑动窗口最值 |

### 四、单调队列优化

当需要在滑动窗口中快速获取最值时，使用单调队列：

```python
from collections import deque

def max_sliding_window(nums, k):
    deq = deque()  # 存储索引，保持递减
    result = []
    
    for i in range(len(nums)):
        # 移除不在窗口内的元素
        while deq and deq[0] <= i - k:
            deq.popleft()
        
        # 保持单调递减
        while deq and nums[deq[-1]] <= nums[i]:
            deq.pop()
        
        deq.append(i)
        
        # 记录答案
        if i >= k - 1:
            result.append(nums[deq[0]])
    
    return result
```

## 例题与应用

### 例题1：最大子数组和（LeetCode 53）
**题目**：给定整数数组，求连续子数组的最大和。

**变长滑动窗口解法**：
```python
def maxSubArray(nums):
    max_sum = nums[0]
    current_sum = nums[0]
    
    for i in range(1, len(nums)):
        # 当前窗口和 + 当前元素 或 从当前元素重新开始
        current_sum = max(current_sum + nums[i], nums[i])
        max_sum = max(max_sum, current_sum)
    
    return max_sum
```

### 例题2：无重复字符的最长子串（LeetCode 3）
**题目**：给定字符串，找出不含重复字符的最长子串长度。

```python
def lengthOfLongestSubstring(s):
    char_index = {}  # 字符到索引的映射
    left = 0
    max_len = 0
    
    for right, char in enumerate(s):
        # 如果字符在窗口中且位置在left之后，收缩窗口
        if char in char_index and char_index[char] >= left:
            left = char_index[char] + 1
        
        char_index[char] = right
        max_len = max(max_len, right - left + 1)
    
    return max_len
```

### 例题3：长度最小的子数组（LeetCode 209）
**题目**：给定数组和目标值，找出连续子数组和 ≥ target 的最小长度。

```python
def minSubArrayLen(target, nums):
    n = len(nums)
    left = 0
    total = 0
    min_len = float('inf')
    
    for right in range(n):
        total += nums[right]
        
        while total >= target:
            min_len = min(min_len, right - left + 1)
            total -= nums[left]
            left += 1
    
    return min_len if min_len != float('inf') else 0
```

### 例题4：字符串排列（LeetCode 567）
**题目**：判断 s2 是否包含 s1 的某种排列。

```python
def checkInclusion(s1, s2):
    from collections import Counter
    
    need = Counter(s1)
    window = Counter()
    left = 0
    valid = 0
    
    for right in range(len(s2)):
        c = s2[right]
        if c in need:
            window[c] += 1
            if window[c] == need[c]:
                valid += 1
        
        # 收缩窗口
        while right - left + 1 >= len(s1):
            if valid == len(need):
                return True
            
            c = s2[left]
            if c in need:
                if window[c] == need[c]:
                    valid -= 1
                window[c] -= 1
            left += 1
    
    return False
```

## 核心概念

哈希表（Hash Table）又称散列表，是根据键（Key）直接访问数据存储位置的数据结构。它通过哈希函数将键映射到表中的位置来访问数据，以实现常数时间级别的查找。

### 基本术语
- **哈希函数**：将键转换为哈希地址的函数
- **哈希地址**：数据在哈希表中的存储位置
- **哈希冲突**：不同键经过哈希函数得到相同地址的现象

## 详细内容

### 一、哈希函数构造

哈希函数的设计直接影响哈希表的性能。好的哈希函数应满足：
- 计算简单高效
- 哈希地址均匀分布
- 冲突少

#### 常用哈希函数

##### 1. 直接定址法
```
H(key) = a × key + b
```
取关键词的线性函数值作为哈希地址。简单且不会冲突，但需要事先知道关键字的分布。

##### 2. 除留余数法
```
H(key) = key mod p
```
最常用的方法，通常取p为不大于表长的素数。

##### 3. 数字分析法
选取关键字中分布均匀的若干位作为哈希地址。

##### 4. 平方取中法
取关键字平方后中间几位作为哈希地址。

##### 5. 折叠法
将关键字分割成位数相等的几部分，然后求和。

### 二、冲突解决方法

#### 1. 链地址法（拉链法）
将所有哈希地址相同的元素链接成一个链表。

```
哈希表
+-------+    +-------+    +-------+
|  0    | -> |  key  | -> |  key  |
+-------+    +-------+    +-------+
|  1    | -> NULL
+-------+    +-------+    +-------+
|  2    | -> |  key  | -> NULL
+-------+    +-------+
|  3    | -> NULL
+-------+    ...
```

**优点**：
- 插入删除操作简单
- 不会产生二次聚集

**缺点**：
- 需要额外空间存储指针
- 链表过长时查找效率下降

**时间复杂度**：
- 理想情况：O(1)
- 最坏情况：O(n)，退化为链表

#### 2. 开放寻址法

所有元素都存储在哈希表数组中，当发生冲突时，按某种探测序列寻找下一个空位置。

##### 线性探测法
```
H(key) = (H(key) + d) mod m, d = 1, 2, 3, ...
```
简单但容易产生"一次聚集"现象。

##### 二次探测法
```
H(key) = (H(key) + d) mod m, d = 1², -1², 2², -2², ...
```
减少了聚集问题，但可能探测不到所有位置。

##### 双重哈希法
```
H(key) = (H1(key) + i × H2(key)) mod m
```
使用两个哈希函数，是开放寻址法中最好的方法之一。

#### 3. 再哈希法
当发生冲突时，使用另一个哈希函数计算下一个地址，直到不冲突为止。

#### 4. 建立公共溢出区
将所有冲突的元素统一存放到公共溢出区中。

### 三、性能指标

| 操作 | 平均时间复杂度 | 最坏时间复杂度 |
|------|---------------|---------------|
| 查找 | O(1) | O(n) |
| 插入 | O(1) | O(n) |
| 删除 | O(1) | O(n) |

**装填因子**（α）= 表中记录数 / 哈希表长度
- α 越大，冲突概率越高
- 通常控制 α 在 0.6~0.7 之间

## 例题与应用

### 例题1：使用除留余数法构造哈希函数
**问题**：将关键字序列 {19, 14, 23, 1, 68, 20, 84, 27, 55, 11, 10, 79} 插入到哈希表中，哈希表长 m=13，用除留余数法 H(key)=key mod 13。

**解答**：
```
H(19) = 19 mod 13 = 6
H(14) = 14 mod 13 = 1
H(23) = 23 mod 13 = 10
H(1)  = 1  mod 13 = 1  → 与14冲突（线性探测：1→2→3→...）
H(68) = 68 mod 13 = 3
H(20) = 20 mod 13 = 7
H(84) = 84 mod 13 = 6  → 与19冲突（线性探测：6→7→8→...）
H(27) = 27 mod 13 = 1  → 冲突
H(55) = 55 mod 13 = 3  → 冲突
H(11) = 11 mod 13 = 11
H(10) = 10 mod 13 = 10 → 冲突
H(79) = 79 mod 13 = 1  → 冲突
```

### 例题2：Python实现哈希表（链地址法）
```python
class HashTable:
    def __init__(self, size=10):
        self.size = size
        self.table = [[] for _ in range(size)]
    
    def hash_function(self, key):
        return key % self.size
    
    def insert(self, key, value):
        index = self.hash_function(key)
        for i, (k, v) in enumerate(self.table[index]):
            if k == key:
                self.table[index][i] = (key, value)
                return
        self.table[index].append((key, value))
    
    def search(self, key):
        index = self.hash_function(key)
        for k, v in self.table[index]:
            if k == key:
                return v
        return None
```


### 应用场景

1. **数据库索引**：加速数据检索
2. **缓存系统**：Redis中的哈希表用于存储对象
3. **编译器符号表**：存储变量名和属性
4. **去重**：快速判断元素是否已存在
5. **海量数据处理**：如在10亿个数中快速查找

## 核心概念

数据结构是计算机存储、组织数据的方式，是指数据元素之间存在一种或多种特定关系的数据元素的集合。

### 数据的三个层次
- **数据**：是描述客观事物的符号，是计算机中可以操作的对象
- **数据元素**：是数据的基本单位，也称为记录
- **数据项**：是数据不可分割的最小单位

### 数据结构研究内容
1. 逻辑结构的定义
2. 存储结构的实现
3. 相关算法的设计

## 详细内容

### 一、逻辑结构分类

数据的逻辑结构是从具体问题中抽象出来的数学模型，反映数据元素之间的逻辑关系。

#### 1. 集合结构
集合中所有元素属于同一集合，数据元素之间除了"属于同一集合"外没有其他关系。
```
集合 = {A, B, C, D}
```

#### 2. 线性结构
数据元素之间存在一对一的关系，每个元素有且仅有一个前驱和一个后继。
```
A → B → C → D → E
```
典型结构：线性表、栈、队列、串

#### 3. 树形结构
数据元素之间存在一对多的关系，每个元素有且仅有一个前驱（根节点除外），但可以有多个后继。
```
      A
       /|\
      B C D
     /|   |
    E F   G
```
典型结构：二叉树、平衡树、B树

#### 4. 图形结构
数据元素之间存在多对多的关系，每个元素可能有多个前驱和多个后继。
```
  A --- B
  |  X  |
  C --- D
```
典型结构：有向图、无向图、网

### 二、存储结构（物理结构）

存储结构是逻辑结构在计算机中的存储方式。

#### 1. 顺序存储结构
- 特点：用一组连续的存储单元依次存储数据元素
- 优点：随机访问效率高，存储密度大
- 缺点：插入删除操作需要移动大量元素，存储空间固定
- 典型结构：数组

```c
// 顺序表示例
int arr[10] = {1, 2, 3, 4, 5};
```

#### 2. 链式存储结构
- 特点：用一组任意的存储单元存储数据元素，节点包含数据和指针
- 优点：插入删除操作方便，不需要连续的存储空间
- 缺点：占用额外空间存储指针，不能随机访问
- 典型结构：链表

```c
// 单链表节点
struct Node {
    ElemType data;
    struct Node *next;
};
```

#### 3. 索引存储结构
- 特点：建立额外的索引表来记录数据位置
- 优点：检索效率高
- 缺点：索引表占用额外空间
- 应用：书籍目录、数据库索引

#### 4. 散列存储结构
- 特点：通过哈希函数直接计算数据存储位置
- 优点：插入、查找、删除效率高
- 缺点：需要处理哈希冲突
- 详见：[[哈希表]]

### 三、算法与复杂度

#### 算法的五个特性
1. **输入**：有零个或多个输入
2. **输出**：有一个或多个输出
3. **有穷性**：执行有限步后自动结束
4. **确定性**：每一步都有明确含义
5. **可行性**：每一步都能在有限时间内完成

#### 时间复杂度
时间复杂度是算法执行时间随输入规模增长的趋势。

| 复杂度 | 名称 | 示例 |
|--------|------|------|
| O(1) | 常数阶 | 数组随机访问 |
| O(log n) | 对数阶 | 二分查找 |
| O(n) | 线性阶 | 遍历数组 |
| O(n log n) | 线性对数阶 | 快速排序 |
| O(n²) | 平方阶 | 冒泡排序 |
| O(2ⁿ) | 指数阶 | 递归Fibonacci |
| O(n!) | 阶乘阶 | 全排列 |

#### 空间复杂度
空间复杂度是算法所需存储空间的度量。
- O(1)：原地操作
- O(n)：需要额外数组或递归栈

## 例题与应用

### 例题1：分析时间复杂度
```c
for (i = 1; i <= n; i++)
    for (j = 1; j <= n; j++)
        printf("%d ", i * j);
```
**分析**：外层循环执行n次，内层循环也执行n次，总执行次数为n×n。
**答案**：O(n²)

### 例题2：顺序存储 vs 链式存储
**场景**：频繁进行插入删除操作
**选择**：链式存储
**原因**：顺序存储插入删除需要移动元素，时间复杂度O(n)；链式存储只需修改指针，时间复杂度O(1)

### 例题3：选择合适的数据结构
**场景**：需要频繁查找第i个元素
**选择**：顺序存储结构（数组）
**原因**：数组可以通过下标直接访问，时间复杂度O(1)
